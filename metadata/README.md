# metadata/

| File | What it is | Who fills it |
|---|---|---|
| `DATA_SOURCES.csv` | Provenance of every downloaded file: version, DOI, download date, resolution, coverage | **You, as you download.** Not reconstructed at the end. |
| `feature_dictionary.csv` | Every feature, its group, unit and definition | Regenerated by `scripts/05_build_master_dataset.py`. The committed version is a naming-scheme template showing month 01 only; the generated one lists all 12 months and the soil columns. |
| `selected_features.txt` | The 20 features chosen per target | Written by `scripts/06_select_features.py` |

The template rows in `feature_dictionary.csv` show the naming scheme:
`<variable>_m<MM>` for monthly climate, `soil_<attribute>` for soil.
